# User Manual

## Executive

Sign in, tap **Attendance**, and use Check in while at the work location. Grant location permission only when prompted. Use the dashboard to review tasks, clients, appointments, activities, published payroll and alerts. Field actions automatically create activity records. Check out at the end of the authorized work period.

## Manager

Sign in to `/admin/login`. Review attendance, KPIs, active tasks and appointments. Manager API access supports task assignment, executive activity, client and latest authorized-location review.

## HR / Accounts

Use the dashboard and HR-authorized APIs for employees, attendance and monthly payroll. HR has no automatic operational ERP administration.

## Administrator

Admin has system-wide access to users, roles, records, reports and audit logs. Replace demo credentials immediately.

## Location and privacy

The app never tracks a worker continuously. Location is recorded only for check-in/out, explicit updates, client visits/onboarding and active field operations.
